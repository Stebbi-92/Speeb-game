HOSTING A FELLOWSHIP OF BRELM
=============================

Brelm's fellowships use one UDP port, 24600 by default. Everyone in a
fellowship must run the same version of Brelm.


1. ON THE SAME NETWORK (home, LAN party)
   Nothing to set up. The host chooses "Walk Together", then "Host a
   fellowship". Everyone else opens "Walk Together", and the fellowship
   appears under "Fellowships found". If it does not, type the address the
   host's gathering place shows (for example 192.168.1.20:24600).

   Windows may ask whether Brelm may use the network. Allow it, on private
   networks at least.


2. OVER THE INTERNET, HOSTING FROM YOUR OWN PC
   When you host, Brelm asks your router to open the port by itself (UPnP).
   The gathering place tells you whether it worked:
     "The router opened UDP port 24600."  Friends join at the internet
        address shown under it.
     "The router did not answer..."  Open the port by hand:
        a. Find this computer's local address in the gathering place
           (for example 192.168.1.20).
        b. In your router's settings, find "Port forwarding" (sometimes
           "Virtual server" or "NAT").
        c. Forward UDP port 24600 to that local address.
        d. Your internet address is at https://ifconfig.me ; friends join
           at that address, port 24600.
   Some internet providers share one address among many homes (CGNAT). If
   forwarding is set up and friends still cannot join, that is the likely
   cause; a dedicated server on a rented machine (below) gets around it.


3. A DEDICATED SERVER (no player of its own)
   Good for a spare PC or a rented Windows or Mac machine with an open port.
   The first pilgrim to join chooses the trial; when everyone leaves, the
   server waits for the next fellowship.

   Windows:  double-click "Brelm Server.bat". The server window opens.
   macOS:    double-click "Brelm Server.command" (it runs in Terminal with
             no window; type commands there, see below).
   Or by hand:
       Brelm.exe -- server
       Brelm.app/Contents/MacOS/Brelm* --headless -- server

   THE SERVER WINDOW
   Along the top: the server's name, whether the world is running or
   paused (and why), players, world, time up, last save, whether it is on
   the internet list, the port and the addresses to join at.
     Players   who is here, with ping. Kick or Ban them, or send a message
               to everyone.
     World     Save now, Restart world, load a saved world or make a new
               one (a seed is optional), and choose when the world runs:
               pause when empty, always run, or paused.
     Settings  name, password, most players, difficulty, internet list,
               autosave, pause when empty, port. Apply puts them in place
               and saves them (a new port needs a restart).
     Updates   check for a new version, read its notes, download it and
               restart the server onto it (the world is saved first). It
               can check by itself at start, and update by itself when no
               one is connected.
     Log       everything the server has said. Copy log, Open log folder.
   Stop server saves the world first and asks before it stops. Closing
   the window also saves and stops.

   WITHOUT A WINDOW (--headless)
   Type commands into the terminal: status, list, save, say <text>,
   kick <name|id>, ban <name|id>, pause, resume, auto, worlds,
   load <world>, new <world> [seed], update, restart, quit, help.

   THE SETTINGS FILE
   The server keeps its settings in server.cfg, in Brelm's data folder:
     Windows:  %APPDATA%\Godot\app_userdata\Brelm- The Hermit of Nine Visions
     macOS:    ~/Library/Application Support/Godot/app_userdata/Brelm- The Hermit of Nine Visions
   (the Settings page shows the exact place). It is made on the first
   start and can be edited by hand while the server is stopped:
       [server]
       name="A fellowship of Brelm"
       port=24600
       password=""
       max_players=8
       difficulty=1          (0 Pilgrim, 1 Hermit, 2 Unblinking)
       listed=false          (show it on the internet list)
       lobby=""              (internet list address; empty for the usual)
       autosave_min=5        (0 for never)
       pause_when_empty=true
       [updates]
       check_on_start=true
       auto_update=false

   Options after "server" override the file for that run:
       config=path         use another settings file
       port=24600          the UDP port to listen on
       name="..."          the fellowship's name in the list
       password=...        the word joiners must give
       max_players=8       most players at once
       difficulty=0|1|2    Pilgrim, Hermit or Unblinking
       autosave=5          minutes between saves
       public              list it on the internet list
       lobby=https://...   the internet list address (see 4)

   The server needs the port open toward it exactly as in section 2. On a
   rented machine, also open UDP 24600 in its firewall / security group.


4. THE INTERNET LIST
   "Fellowships found" shows fellowships on your own network, and public
   ones from the internet list at https://game.speeb.org
   (built into the game). Tick "List on the internet" when hosting to
   appear there. The list keeps nothing on disk; a fellowship drops off two
   minutes after its host stops announcing it.
   The list service is in tools/lobby/ of the source (a Cloudflare Worker).
   To move it elsewhere, deploy it with "npx wrangler deploy" and set the
   new address in Options > Fellowship > Internet list address.
