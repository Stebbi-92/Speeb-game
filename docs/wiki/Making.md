# Making

_This page is made from the game's own data by `tools/wiki.gd`. Edit the game, not this page._

Open your pack (**I**) and choose **Make**. Inside a base, the chests of that base count as part of your pack, so there is no need to fetch things first. Some things need a **workbench** or a **cooking station** close by.
