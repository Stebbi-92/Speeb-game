# Skills

_This page is made from the game's own data by `tools/wiki.gd`. Edit the game, not this page._

Everything you do earns experience. Each level gives a point to spend; press **K** to see the skills. Deeper skills open as you level (the tier is the level at which they open).

| **Light Step** | 2 | level 3 | Walk and run 5% faster for each rank. |
| **Deep Pockets** | 2 | level 5 | Four more places in your pack for each rank. |
